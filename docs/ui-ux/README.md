# Dossier UI/UX — règles, techniques et sources

Référence de conception d'interfaces (UI) et d'expérience utilisateur (UX), rédigée en français à
partir de sources publiques citées au fil du texte.

## Volume réel (annoncé sans arrondi)

- **41 chapitres**, environ **54 190 mots** (tableaux inclus) ;
- **202 sources** référencées avec leur URL : [`SOURCES.md`](SOURCES.md) ;
- **30 images** libres de droits (Wikimedia Commons) : [`images/CREDITS.md`](images/CREDITS.md).

Ordre de grandeur : à 400–500 mots par page de texte courant, cela représente environ
108 à 135 pages, soit **moins que les 200 pages visées**. La matière brute collectée
(plusieurs millions de caractères) est bien plus volumineuse mais n'a pas été recopiée
(reformulation et citation uniquement). Voir les limites au
[chapitre 1](chapitres/01-introduction-et-methode.md).
